# Repositorios de Referencia e Indexación Técnica

Este directorio contiene las copias locales de referencia (`depth=1`) de los repositorios fuente clave para el ecosistema de diseño determinista y arquitectura agéntica.

## UI, Estética y Frontend (Anti-Slop)

1. **impeccable** (`pbakaus/impeccable`): Vocabulario y heurística de diseño determinista sin opacidad.
2. **antigravity-awesome-skills** (`sickn33/antigravity-awesome-skills`): Catálogo de habilidades agénticas avanzadas.
3. **antigravity_global_skills** (`krishnakanthb13/antigravity_global_skills`): Habilidades UI/UX Pro Max.
4. **tailwindcss** (`tailwindlabs/tailwindcss`): Tailwind CSS v4 con directiva `@theme`.
5. **shadcn-ui** (`shadcn-ui/ui`): Componentes UI inyectables de código abierto.
6. **radix-primitives** (`radix-ui/primitives`): Primitivas sin estilo accesibles (WAI-ARIA).
7. **magicui** (`magicuidesign/magicui`): Efectos espaciales y micro-interacciones.
8. **motion** (`motiondivision/motion`): Coreografía de movimiento determinista (Framer Motion).
9. **lenis** (`darkroomengineering/lenis`): Motor de scroll suave homogéneo.
10. **axe-core** (`dequelabs/axe-core`): Motor de auditoría de accesibilidad.

## Arquitectura, Backend & Agentes

1. **temporal** (`temporalio/temporal`): Ejecución durable y patrón Saga.
2. **dagster** (`dagster-io/dagster`): Activos definidos por software (SDA) para pipelines de datos/RAG.
3. **langgraph** (`langchain-ai/langgraph`): Grafo de agentes con pausa Human-in-the-Loop (HitL).
4. **crewAI** (`crewAIInc/crewAI`): Enjambres de agentes para tareas colaborativas.
5. **flyte** (`flyteorg/flyte`): Orquestación ML fuertemente tipada.
6. **argo-workflows** (`argoproj/argo-workflows`): Flujos de trabajo efímeros en Kubernetes.
7. **kestra** (`kestra-io/kestra`): Orquestación guiada por eventos (Event-Driven YAML).
8. **starter-workflows** (`actions/starter-workflows`): Flujos de CI/CD para GitHub Actions.
